# 视频生成（工具方式）

视频生成通过**媒体生成工具**完成，模型由用户在**设置 → 媒体生成模型**里配置。
本 skill 只负责告诉你**怎么用这个工具**，以及**怎么做镜头与提示词决策**。

**不要**尝试用脚本、`curl` 或环境变量直接调用视频 API。密钥与接口地址都在设置页，
工具会自己读取。轮询与超时也由工具接管，你不需要自己轮询。

## 前置条件

用户必须先在设置里配置至少一个视频模型。若 `action=list` 返回空列表，说明还没配，
此时应当**告知用户去「设置 → 媒体生成模型 → 视频生成模型」添加**。

配置示例（供用户参考，接口地址以火山方舟为例）：

| 字段 | 填写内容 |
| --- | --- |
| 接口地址 | `https://ark.cn-beijing.volces.com/api/v3` |
| 模型 ID | 例如 `doubao-seedance-1-5-pro-251215` |
| API 密钥 | 火山方舟控制台的 API Key |

## 使用流程

### 1. 先列出可用模型

调用 `action=list`。它会返回用户配置的所有视频模型、每个模型的能力说明，
以及**该类模型接受的全部参数**（含类型、是否必填、示例值）。

**视频时长与宽高比的可选范围随模型而变**，所以必须先看这一份列表，不要套用默认值。

### 2. 提交生成任务

调用 `action=generate`，常用参数：

| 参数 | 用途 |
| --- | --- |
| `prompt` | 必填。视频描述，含镜头语言 |
| `model` | 上一步列出的模型 ID |
| `durationSeconds` | 时长（秒），取值范围依模型；`-1` 为自动 |
| `aspectRatio` | 宽高比，如 `16:9` / `9:16` / `1:1` / `adaptive` |
| `resolution` | `480p` / `720p` / `1080p` |
| `image` / `images` | 参考图；配合 `imageRoles` 标注角色 |
| `firstFrame` / `lastFrame` | 首尾帧，用于做过渡动画 |
| `audio` | 是否生成同步音频（部分模型支持） |
| `watermark` | 是否加水印 |
| `cameraFixed` | 锁定镜头（不运动），部分模型支持 |
| `returnLastFrame` | 额外返回尾帧 PNG，便于连续片段衔接 |
| `seed` | 随机种子，`-1` 为随机；同种子同参数结果相近 |
| `providerOptions` | 模型私有参数，原样透传 |

### 3. 任务是异步的

视频生成**必然返回 `taskId`**，任务处于 `queued` / `running` 状态。

- 用 `action=status` + `taskId` 查询进度
- 任务到达 `succeeded` 后，结果 URL 才会给出
- 任务失败或超时：用 `action=cancel` 取消后重试

不要在一次回复里反复轮询；提交任务后告诉用户正在生成，等任务回调或用户追问时再查。

用户已在输入框选定了模型时，工具会明确要求你必须用该模型，不要自行更换。

## 场景用法

### 文生视频（T2V）

只给 `prompt`。提示词里写清**主体 + 动作 + 镜头运动 + 场景**。

### 图生视频（I2V）

给 `image` 作为首帧 + 动作指令。适合「让这张图动起来」。

### 首尾帧过渡

给 `firstFrame` + `lastFrame`，模型自动补出中间的运镜。适合转场、连续片段。

### 多参考图融合

给 `images` + `imageRoles`（取值 `first_frame` / `last_frame` / `reference_image`），
数组长度必须与角色数组一致。适合多角色同框、道具与场景融合。

### 音画同步

部分模型（如 Seedance 1.5 pro）支持 `audio`。此时把**对白、音效、配乐要求直接写进
prompt**，例如「她用京剧唱腔唱『月移花影』，唱词充满情感，环境有雨声」。
不要只在参数里开 `audio` 而不描述声音内容。

## 镜头语言提示词

| 想要的效果 | 写法 |
| --- | --- |
| 推进 | 「镜头缓缓推进」「逐渐推近至面部特写」 |
| 环绕 | 「360 度环绕运镜，流畅过渡」 |
| 固定 | 「镜头固定不动，画面中角色缓慢转头」 |
| 跟随 | 「跟拍角色穿过街道」 |
| 俯视 | 「高空俯视，缓慢下降」 |

## 时长与画幅选择

| 用途 | 画幅 | 建议时长 |
| --- | --- | --- |
| 短视频 / 竖屏分发 | `9:16` | 短 |
| 横屏内容（B站、YouTube） | `16:9` | 中等 |
| 社交方图 | `1:1` | 短 |

先出短时长确认运镜正确，再出长时长版本。高分辨率或长时长耗时显著增加。

用户在设置里配置的模型决定实际能力。以下是火山方舟 Seedance 系列的常见配置，
可作为推荐给用户的候选：

| 模型 ID | 特点 | 限流（RPM / 并发） |

## 排错

| 现象 | 处理 |
| --- | --- |
| 列出模型为空 | 用户还没配置视频模型，引导去设置页添加 |
| 提示缺少 API 密钥 | 该条目在设置里未填密钥，请用户补填 |
| 提示缺少模型 ID | 设置页该条目未填模型 ID，无法被 `action=list` 收录 |
| 时长或画幅报错 | 该取值不在此模型范围内，查 `action=list` 说明后重选 |
| 任务长时间 `queued` | 命中限流或上游繁忙，建议换 lite 模型或稍后重试 |
| 任务 `failed` | 看错误信息；若是内容审核拦截，调整描述后重试 |
