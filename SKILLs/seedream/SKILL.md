# 图片生成（工具方式）

图片生成通过**媒体生成工具**完成，模型由用户在**设置 → 媒体生成模型**里配置。
本 skill 只负责告诉你**怎么用这个工具**，以及**怎么写提示词**。

**不要**尝试用脚本、`curl` 或环境变量直接调用图片 API。密钥与接口地址都在设置页，
工具会自己读取。

## 前置条件

用户必须先在设置里配置至少一个图片模型。若 `action=list` 返回空列表，说明还没配，
此时应当**告知用户去「设置 → 媒体生成模型 → 图片生成模型」添加**，而不是自己去找密钥。

配置示例（供用户参考，接口地址以火山方舟为例）：

| 字段 | 填写内容 |
| --- | --- |
| 接口地址 | `https://ark.cn-beijing.volces.com/api/v3` |
| 模型 ID | 例如 `doubao-seedream-4-5-251128` |
| API 密钥 | 火山方舟控制台的 API Key |

## 使用流程

### 1. 先列出可用模型

调用工具的 `action=list`。它会返回用户配置的所有图片模型、每个模型的能力说明，
以及**该类模型接受的全部参数**（含类型、是否必填、示例值）。

必须先做这一步，不要凭记忆猜模型名或参数。

### 2. 再生成

调用 `action=generate`，常用参数：

| 参数 | 用途 |
| --- | --- |
| `prompt` | 必填。图片描述 |
| `model` | 上一步列出的模型 ID |
| `image` / `images` | 参考图，支持本地路径、URL 或 data URL |
| `size` | 输出尺寸，如 `1024x1024` |
| `imageSize` | 使用 imageConfig 的模型填 `1K` / `2K` / `4K` |
| `n` / `count` | 生成张数 |
| `quality` | 质量，如 `high` |
| `outputFormat` | `png` / `jpeg` / `webp` |
| `watermark` | 是否加水印 |
| `providerOptions` | 模型私有参数，原样透传 |

用户已在输入框选定了模型时，工具会明确要求你必须用该模型，不要自行更换。

### 3. 长任务用状态查询

视频类模型是异步的，图片类一般同步返回。若工具返回 `taskId`，用 `action=status`
查询，中途可用 `action=cancel` 取消。

## 场景用法

### 文生图（T2I）

只给 `prompt`，适合创意激发与概念设计。

### 图片编辑（I2I）

给 `image` + 指令，例如「把背景换成海边日落，人物保持不变」。
支持 jpg / png / gif / webp / heic 等常见格式的本地文件与网络 URL。

### 多图融合

给 `images`（多张）+ 指令。适合场景合成、角色一致性保持、风格迁移。

### 组图生成

给 `n` 或 `count` 一次出多张，适合漫画分镜、品牌视觉。输出会自动编号。

### 联网搜索增强

部分模型（如 Seedream 5.0 lite）支持联网检索最新信息后生成，通过
`providerOptions` 传模型要求的开关。只有模型文档明确要求时才传。

## 提示词实践

好的提示词让出图一次到位，减少反复生成：

1. **主体明确** —— 说清画面的主要内容，而不是含糊的氛围词
2. **细节具体** ——「小猫在追逐蝴蝶」优于「小猫玩耍」
3. **风格与光照** —— 写清想要的画风、色调、光线方向
4. **构图视角** —— 特写、全景、俯视、俯仰角等
5. **避免违规** —— 不含暴力、色情等违规内容

可用模板：

```
[主体描述]，[场景/背景]，[风格]，[光照]，[构图视角]
```

例：`一只橘猫在窗台上看雨，暖色调，柔和侧光，写实摄影风格，特写`

## 尺寸与耗时

`1K` 适合快速预览与草稿，`2K` 是日常推荐，`4K` 出图较慢（可能需要数十秒）。
追求效率时先出小图确认构图，再出大图。

## 已知模型参考

用户在设置里配置的模型决定实际能力。以下是火山方舟 Seedream 系列的常见配置，
可作为推荐给用户的候选：

| 模型 ID | 特点 | 限流 |
| --- | --- | --- |
| `doubao-seedream-4-5-251128` | 综合质量最佳，推荐 | IPM 500 |
| `doubao-seedream-4-0-250828` | 成熟稳定 | IPM 500 |
| `doubao-seedream-5-0-260128` | 支持联网搜索增强 | 依官方文档 |

若用户配置的是其他供应商的模型，以 `action=list` 的返回为准，不要套用上表。

## 排错

| 现象 | 处理 |
| --- | --- |
| 列出模型为空 | 用户还没配置图片模型，引导去设置页添加 |
| 提示缺少 API 密钥 | 该条目在设置里未填密钥，请用户补填 |
| 提示缺少模型 ID | 设置页该条目未填模型 ID，无法被 `action=list` 收录 |
| 接口报错 401 / 403 | 密钥无效或已过期 |
| 出图内容不合预期 | 提示词不够具体，按上文「提示词实践」补主体、风格与构图 |
